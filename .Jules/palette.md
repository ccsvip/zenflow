## 2026-05-28 - [Add Loading States for Async Operations]\n**Learning:** The app's main page and login form were missing loading and error states, leading to confusing empty screens (flashing 'No projects') or silent failures before async operations finished. Providing immediate visual feedback (like a Spinner) during data fetches significantly improves perceived performance and clarifies system status.\n**Action:** Use the existing `<Spinner>` and `<EmptyState>` components from the UI library to properly handle `loading` and `error` states for async fetch operations going forward.
